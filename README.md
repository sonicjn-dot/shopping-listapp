# 쇼핑 리스트 앱

간단하고 실용적인 쇼핑 리스트 관리 웹 애플리케이션입니다.

## 기능

- ✅ 쇼핑 아이템 추가/삭제
- ✅ 체크박스로 완료 표시
- ✅ 로컬 스토리지를 통한 데이터 저장
- ✅ 반응형 디자인
- ✅ 실시간 통계 (전체/완료 개수)

## 사용 방법

1. `shopping-list.html` 파일을 브라우저에서 열기
2. 입력란에 구매할 아이템 입력
3. "추가" 버튼 클릭 또는 Enter 키 입력
4. 체크박스를 클릭하여 구매 완료 표시
5. "삭제" 버튼으로 아이템 제거

## 기술 스택

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API
